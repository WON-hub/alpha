# 발표용 CSV 참고자료

이 폴더의 CSV는 서비스의 데이터 처리 흐름을 설명하기 위한 참고용 스냅샷입니다. 실제 운영 데이터의 원본은 Supabase Postgres입니다.

## 파일 설명

### `01_survey_results.csv`

유효 설문 응답 31건입니다. 각 응답은 혜택(B), 만족도(S), 거리(D)에 총 10점을 배분한 결과이며, 마지막 세 컬럼은 각 응답을 10점 기준으로 정규화한 비율입니다.

응답 평균을 다시 정규화하면 다음 가중치가 됩니다.

```text
B = 52.58%
S = 20.32%
D = 27.10%
```

### `02_partnerships_before_ai.csv`

AI 분석 전 원본 제휴등록 데이터 45건입니다. 일괄등록에 사용하는 표준 컬럼만 포함합니다.

```text
가게명, 카테고리, 주소, 위도, 경도, 제휴대상, 혜택, 시작일, 종료일
```

### `03_partnerships_after_ai_db_snapshot.csv`

현재 Supabase에서 AI 혜택 전처리가 완료된 제휴정보 31건을 추출한 스냅샷입니다. 원문 혜택, AI 분석 JSON, 기본점수, 추가점수, 조건감점, 최종 혜택점수 B, 베이즈 만족도 S를 함께 보여줍니다.

최종 CDI는 포함하지 않습니다. 거리점수 D가 사용자의 현재 위치에 따라 달라지기 때문입니다. 따라서 이 파일은 “AI 전처리 결과가 DB에 저장된 모습”을 보여주고, CDI는 앱의 추천 요청 시 계산합니다.

### `Benefit_example.csv`

Supabase의 `restaurant_id=174`인 `수해복마라탕` 한 건을 자세히 펼쳐 놓은 예시입니다. 원본 혜택 문장, AI가 만든 구조화 JSON, 기본 혜택점수·추가 혜택점수·조건 감점, 최종 혜택점수 B, 혜택 등급, 리뷰 기반 베이즈 만족도 S를 한 행에서 비교할 수 있습니다.

예시의 B 점수는 `60 + 0 - 20 = 40`으로 계산되며, 사용자 위치에 따라 바뀌는 거리점수 D와 합쳐지는 최종 CDI는 이 참고자료에 고정하지 않았습니다.
